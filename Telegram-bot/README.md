
```markdown
Разработка Telegram-бота для автоматизации заказов в кафе <<Стамбул>>

Третья итерация модернизации. Состояние:

UX-кнопки — переименованы по принципу «глагол + объект, 2–3 слова»
152-ФЗ — согласие пользователя, шифрование ПДн через Fernet
Поддержка — FAQ + контакт администратора (через ссылку на username или прямой ID)
Двусторонний чат с курьером — пользователь ↔ курьер (не через WebApp)
Скрытие/возврат блюд — выбор из списка с пагинацией
Найм курьера через контакт — админ пересылает контакт человека из своих контактов
Скидки — рубли/процент, бессрочные или со сроком окончания
Оплата — перевод (с номером курьера) или наличные
Рейтинг курьеров — 1–5 ⭐ после доставки, сортировка курьеров по нему
Таймаут заказа 5 минут — автореассайнмент следующему по рейтингу
Отчёты — для курьера (доставлено / сумма) и админа (выручка по способам + по курьерам), Excel
Неоплаченные заказы — курьер может отмечать заказы как оплаченные/неоплаченные и просматривать свои неоплаченные заказы
```

## Установка

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка

1. `cp .env.example .env` (на Windows: `copy .env.example .env`)
2. Сгенерируйте Fernet-ключ: `python crypto_utils.py` → положите в `.env` как `FERNET_KEY`
3. Получите токен бота у @BotFather (если старый утёк — отзовите через `/revoke`)
4. Узнайте свой chat_id у @userinfobot → `ADMIN_CHAT_ID`
5. (Опционально) Установите `ADMIN_USERNAME` для прямой ссылки в поддержке
6. Заполните `.env`:

```
BOT_TOKEN=ваш_токен
ADMIN_CHAT_ID=ваш_id
ADMIN_USERNAME=ваш_username      # опционально, для кнопки поддержки
DB_PATH=data/bot.db
FERNET_KEY=ваш_ключ
CONSENT_VERSION=1.0
PRIVACY_POLICY_URL=https://telegra.ph/Politika-konfidencialnosti
```

## Миграция старой БД

Только если у вас была старая БД с ПДн в открытом виде:

```bash
cp "/путь/к/старой/bot.db" data/bot.db    # macOS/Linux
copy "путь\к\старой\bot.db" data\bot.db   # Windows

# обязательно бэкап!
cp data/bot.db data/bot.db.bak

python migrations/encrypt_existing.py
```

Скрипт идемпотентен — повторный запуск ничего не сломает.

## Запуск

```bash
python bot.py
```

При первом запуске создастся `data/bot.db` со всей новой схемой
(пользователи, меню, корзина, заказы, курьеры с телефонами для перевода,
рейтинг, скидки, логи действий, согласия).

## Сценарии использования

### Заказ

1. Юзер: `/start` → главное меню
2. «📱🏠 Заполнить профиль» → согласие на ПДн → телефон → адрес → ФИО
3. «🚴 Выбрать курьера» → инлайн-список с рейтингом
4. «📋 Смотреть меню» → клик по блюду (со скидкой цена показывается перечёркнутой → новой)
5. «🛒 Открыть корзину» → «💳 Выбрать оплату» (перевод или наличные) → «✅ Подтвердить заказ» → (опционально) комментарий
6. **При оплате переводом** — клиенту в чат приходит номер курьера для перевода и просьба указать номер заказа в комментарии
7. **При наличными** — просьба передать сумму при получении
8. У курьера 5 минут на «✅ Принять». Если не успел или нажал «❌ Отклонить» — заказ автоматически уходит следующему курьеру по рейтингу. Сообщение у первого курьера обновляется на «передан другому».
9. Курьер жмёт «✅ Завершить» после доставки → юзеру приходит запрос оценки 1–5 ⭐
10. Курьер отмечает, оплачен ли заказ (кнопки «✅ Оплачено» / «❌ Не оплачено»)

### Неоплаченные заказы

Курьер может в любое время нажать «📋 Неоплаченные заказы»:
* Видит список всех своих доставленных, но неоплаченных заказов
* Для каждого заказа показаны контактные данные клиента
* Может отметить заказ как оплаченный прямо из списка

### Скидки

Админ-панель → «🏷 Скидки»:
* Видит список активных скидок (если есть)
* «➕ Добавить скидку» → выбрать категорию → выбрать блюдо → выбрать тип (% или ₽) → ввести значение → срок (бессрочно / 1 / 3 / 7 дней)
* «❌ Убрать скидку» — выбор из активных

### Найм курьера

Админ-панель → «➕ Нанять курьера»:
1. Бот просит переслать контакт через скрепку → Контакт
2. Из контакта Telegram автоматически берётся имя, chat_id и телефон
3. Курьер должен хотя бы раз нажать `/start` у бота — иначе бот не сможет ему писать
4. После найма у курьера появится кнопка «📊 Мой отчёт» и «📋 Неоплаченные заказы» в главном меню

### Отчёты

* **Админ** → «📊 Отчёт по выручке» → выбрать период (сегодня / неделя / месяц / свой / всё время)
  → текстовая сводка + Excel-файл с листами «Заказы» и «Сводка»
* **Курьер** → «📊 Мой отчёт» → тот же выбор периода →
  свой текстовый отчёт + личный Excel

### Поддержка

1. Юзер: «💡 Поддержка и помощь» → бот показывает FAQ и кнопку для связи с администратором
2. Если в `.env` указан `ADMIN_USERNAME` — кнопка открывает чат с ним
3. Если `ADMIN_USERNAME` не указан — отправляется системное сообщение с chat_id админа
4. **Чаты с курьером**: кнопка «📩 Чат с доставщиком» → пользователь пишет сообщение → курьеру приходит с кнопкой «💬 Ответить» → двусторонний обмен сообщениями
