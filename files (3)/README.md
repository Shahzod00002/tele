# Бот кафе «Стамбул» — VK-версия

Полный порт Telegram-бота на платформу VK. **Все 151 хэндлер из исходника реализованы.**

## Что бот умеет

### Клиент
- Заполнение профиля (с согласием на ПДн по 152-ФЗ)
- Просмотр меню по категориям, поиск блюд
- Фото блюд (через VK photo-attachment)
- Корзина с управлением количеством
- Оформление заказа: выбор оплаты (перевод/наличные), комментарий
- Выбор Доставщика по рейтингу
- Отмена заказа клиентом, повтор отменённого
- Оценка Доставщика 1–5 ⭐
- Чат с Доставщиком (двусторонний)
- Поддержка: FAQ + связь с админом
- «📦 Мои заказы» + «📜 История» (TXT / DOCX / в чате)
- «🏠 Сменить адрес»

### Курьер
- «📊 Мой отчёт» с Excel-файлом
- «📋 Неоплаченные заказы» с возможностью отметить как оплаченные
- «📞 Мой номер для переводов»
- Принять / Отклонить заказ (с автореассайнментом по таймауту 5 мин)
- Завершение доставки + отметка «Оплачено / Не оплачено»

### Админ
- **Меню**: добавить/удалить блюдо, изменить цены, скрыть/вернуть, фото (загрузка/удаление)
- **Категории**: добавить/удалить с каскадом
- **Курьеры**: нанять (3 способа: ID, ссылка, forward), уволить, изменить номер
- **Скидки**: % или ₽, бессрочно / 1 / 3 / 7 дней
- **Отчёты по выручке** с Excel: сегодня / неделя / месяц / всё / произвольный период
- **«📋 Все заказы»** в текстовом виде
- **База пользователей**: пагинация, карточка, редактирование, удаление
- **Рассылки**: всем пользователям и всем курьерам
- **Поиск VK-ID** по номеру заказа
- **Экспорт меню** в JSON-файл
- **Импорт меню** из JSON (очистить / дополнить)

## Подготовка сообщества VK

1. Создайте сообщество (тип «Бизнес» или «Заведение»).
2. **Управление → Сообщения**:
   - Включите «Сообщения сообщества»
   - В «Возможности ботов» включите оба пункта: «Возможности ботов» + «Добавлять кнопку Начать»
3. **Управление → Работа с API**:
   - Создайте ключ доступа с правами: `messages`, `photos`, `manage`, `docs`
   - Скопируйте токен → `VK_TOKEN` в `.env`
   - **Long Poll API**: включите, версия 5.199 (или последняя доступная)
4. Запомните `group_id` (число) → `VK_GROUP_ID`
5. Назначьте бота администратором беседы, если хотите работать в чатах сообщества

## Настройка `.env`

```bash
cp .env.example .env
python crypto_utils.py     # сгенерирует Fernet-ключ → положите в FERNET_KEY
```

Заполните `.env`:

```
VK_TOKEN=ваш_токен_сообщества
VK_GROUP_ID=123456789
ADMIN_VK_ID=ваш_числовой_VK_ID
ADMIN_VK_SCREEN=ваш_username     # опционально — для прямой ссылки в поддержке
DB_PATH=data/bot.db
FERNET_KEY=...
CONSENT_VERSION=1.0
PRIVACY_POLICY_URL=https://telegra.ph/Politika-konfidencialnosti
ENABLE_CHATS=1
```

Узнать свой числовой VK-ID: https://regvk.com/id/

## Перенос БД из Telegram-версии

База данных совместима по схеме, но **ID пользователей не совпадают**: в Telegram это chat_id, в VK — VK user ID. Решений три:

1. **Стартовать с пустой БД** (самый простой) — `data/bot.db` не копируется, миграции запустятся при первом старте.
2. **Сохранить только меню/категории/курьеров** — через экспорт меню в Telegram-версии и импорт в VK-боте (для меню), курьеров переназначить заново.
3. Маппинг `telegram_chat_id → vk_user_id` — но это требует ручного сбора данных от пользователей.

Если в `menu.photo` остались старые Telegram `file_id` — в VK они не сработают, нужно загрузить фото заново через «📸 Добавить фото».

## Ключевые отличия от Telegram

| Telegram | VK |
|---|---|
| `pyTelegramBotAPI` (синхронный) | `vk_api` + `VkBotLongPoll` (синхронный) |
| `ReplyKeyboardMarkup` | `keyboard` JSON, до **7 рядов** на практике |
| `InlineKeyboardMarkup` | `keyboard` с `inline:true`, **до 6 рядов** |
| Системная кнопка «Поделиться телефоном» | **Нет** — ввод вручную |
| Forward контакта при найме курьера | **Нет** — ссылка/ID/forward сообщения |
| `file_id` для фото | `attachment="photo<owner>_<id>[_<key>]"` |
| `bot.send_document` | upload через `VkUpload.document_message` |
| `bot.send_photo` | `attachment="photo<owner>_<id>"` |
| Скачивание присланного файла через `get_file` | `requests.get(attachment.doc.url)` |
| Markdown (`*жирный*`) | **Только plain text** + эмодзи |
| `parse_mode` | **Нет** |
| `register_next_step_handler` | Свой роутер `STATE_HANDLERS` |
| ~16 рядов кнопок в одной клавиатуре | Разбито на 3 подменю в админ-панели |
